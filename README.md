# Yash Lahane — Developer Portfolio

A personal developer portfolio showcasing my projects, technical skills, experience, and background. Built with a focus on clean design, subtle motion, interactive elements, and a responsive user experience.

## Overview

This portfolio is a place to showcase my work, explore the technologies I use, and share more about my journey as a developer.

The website combines a minimal visual style with interactive details and motion effects to create an engaging browsing experience.

## Features

- **Terminal-style Loading Screen** — A custom boot sequence with a progress indicator and animated status messages.
- **Animated Navigation** — Responsive navigation with a mobile hamburger menu.
- **Motion Effects** — Scroll-triggered animations and interactive cursor effects.
- **Responsive Design** — Adapted for desktop, tablet, and mobile screens.
- **Reduced Motion Support** — Respects the user's motion preferences.

## Tech Stack

| Technology | Purpose |

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/Yaash001/portfolio
```

Navigate into the project:

```bash
cd yash-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | Starts the development server |
| `npm run build` | Creates a production build |
| `npm run start` | Starts the production server |
| `npm run lint` | Runs ESLint |
